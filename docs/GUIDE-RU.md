# NPC Spawner — руководство пользователя

Подробный гайд: что делает мод, где и что настраивается, что делают команды,
как понять, что всё работает, и что делать, если что-то не так.

---

## Что это такое

**NPC Spawner** — мод для **сервера** V Rising (версия игры 1.1.x).
Он в случайные моменты появляет группу НПС рядом со случайным игроком,
а за убийство этих НПС выдаёт настраиваемую добычу.

> ### ⚠️ Только для сервера
> Мод ставится **только на сервер**. Клиентам (игрокам) ничего скачивать и устанавливать не нужно —
> они просто играют. Мод не даёт преимуществ и не меняет клиент.
>
> Если поставить его на клиент — он ничего не сделает: вся логика серверная.

### Что мод делает

- выбирает **случайного игрока онлайн** и **случайную группу НПС** из конфига;
- появляет группу **вокруг этого игрока** в заданном радиусе, в **случайный момент времени**;
- за убийство НПС игрок получает **настроенную добычу**;
- присылает **цветные сообщения** в чат: о появлении группы, о добыче и о том, что игрок справился с задачей;
- **не спавнит** НПС в замках игроков, под крышами и рядом с игроками, которые находятся в бою.

## Что нужно на сервере

| Компонент | Зачем |
|---|---|
| **BepInExPack V Rising** | загрузчик модов (без него моды не работают) |
| **Vampire Command Framework** (VCF) | чтобы работали команды в чате |

 Оба ставятся через мод-менеджер (r2modman / Thunderstore Mod Manager) или вручную в `BepInEx/plugins`.

---

## Установка

1. Установи на сервер **BepInExPack V Rising** и **Vampire Command Framework**.
2. Скопируй файл **`NpcSpawner.dll`** в папку:
   ```
   <папка сервера>/BepInEx/plugins/
   ```
   (туда же, где лежат остальные моды).
3. Запусти сервер **один раз** — мод сам создаст файлы настройки.
4. Открой их, поправь под себя и перезапусти сервер (или примени команду `.npcs reload` в игре).

Если сервер на хостинге — файлы загружаются через файловый менеджер панели, а если панель умеет
ставить наборы модов, можно загрузить готовый архив пакета.

## Что и где настраивается

После первого запуска появятся три файла:

```
<папка сервера>/BepInEx/config/NpcSpawner/
├── npcs.json         ← КАКИЕ НПС и СКОЛЬКО спавнить (группы)
├── loot.json         ← ЛУТ за убийство НПС (по id НПС)
└── NpcSpawner.cfg    ← общие настройки: интервал, правила спавна, тексты сообщений
```

> **Важно.** BepInEx никогда не перезаписывает значения, которые уже есть в `.cfg` —
> он только дописывает новые строки. Поэтому после обновления мода новые настройки появятся,
> а **значения старых останутся прежними**. Чтобы применить значения по умолчанию —
> удали `NpcSpawner.cfg` и перезапусти сервер. `npcs.json` и `loot.json` удалять не нужно.

### `npcs.json` — что и сколько спавнить

Это словарь «групп». Название группы придумываешь сам — оно потом используется в команде
`.npcs spawn <группа>`.

```json
{
  "night": {
    "RandomAround": 8,
    "Prefabs": {
      "2111003460": 2,
      "-494298686": 2,
      "1980594081": 2
    }
  },
  "horde": {
    "RandomAround": 18,
    "Prefabs": {
      "2111003460": 3,
      "-1722278689": 10
    }
  }
}
```

| Поле | Что значит |
|---|---|
| `RandomAround` | радиус в метрах вокруг выбранного игрока, в котором появятся НПС |
| `Prefabs` | `{ "id НПС": сколько штук }` — можно указать несколько видов НПС в одной группе |

Групп может быть сколько угодно. Каждый спавн выбирается **одна случайная группа** из файла.

**Где брать id НПС:** на [V Rising Mod Wiki → NPCs](https://wiki.vrisingmods.com/prefabs/CHAR)
либо с помощью мода **KindredExtract** (он выгружает в файл все префабы игры с id).

### `loot.json` — добыча за убийство

Ключ — это **id НПС** из `Prefabs`. Значение — список предметов.

```json
{
  "2111003460": [
    { "ItemId": 429052660, "Amount": 1, "Chance": 0.5 },
    { "ItemId": -77477508, "Amount": 2, "Chance": 1.0 }
  ]
}
```

| Поле | Что значит |
|---|---|
| `ItemId` | id предмета |
| `Amount` | сколько штук выдать |
| `Chance` | шанс выпадения от `0` до `1` (`1` = всегда) |

Добыча кладётся **в инвентарь убийцы**, а если инвентарь полон — падает рядом на землю.

### `NpcSpawner.cfg` — общие настройки

#### Секция `[General]`

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `Enabled` | `true` | включён ли автоматический случайный спавн |
| `IntervalMinSeconds` | `300` | минимальный интервал между спавнами, секунды |
| `IntervalMaxSeconds` | `600` | максимальный интервал между спавнами, секунды |
| `IntervalScalesWithPlayers` | `false` | если `true` — интервал делится на число игроков онлайн (больше игроков → чаще спавн) |
| `LifetimeSeconds` | `0` | сколько секунд живёт заспавненный НПС (`0` — бессрочно, до убийства) |

#### Секция `[Spawn]` — правила, где спавнить нельзя

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `BlockNearCastles` | `true` | запрет спавна в замках игроков и под крышами |
| `CastleBlockRadius` | `4` | радиус в метрах вокруг плит замка, где спавн запрещён |
| `CastleHeartRadius` | `30` | радиус в метрах вокруг **сердца замка**, где спавн запрещён (закрывает любой этаж) |
| `SkipPlayersInCombat` | `true` | не спавнить у игрока, который находится в бою |
| `CombatBuffGuids` | `581443919,697095869` | id баффов «в бою» через запятую (обычный и PvP бой) |

#### Секции `[Messages]` и `[Loot]` — тексты сообщений

Все сообщения **цветные**: цвет задаётся тегами `<color=#RRGGBB>...</color>` прямо в тексте.
Например `<color=#3cff8a>зелёный текст</color>`.

| Настройка | Что это |
|---|---|
| `Announce` / `AnnounceMessage` | сообщение **лично** игроку, когда рядом появилась группа |
| `GlobalAnnounce` / `GlobalSpawnMessage` | сообщение **всем** игрокам, что у кого-то произошёл случайный спавн |
| `NotifyKiller` / `NotifyMessage` | сообщение **лично** убийце о полученной добыче |
| `SuccessAnnounce` / `SuccessMessage` | сообщение **всем**, что игрок справился с задачей (убил всю группу) |

Подстановки в текстах:

- `AnnounceMessage`: `{0}` — имя группы, `{1}` — сколько врагов;
- `GlobalSpawnMessage`: `{0}` — ник игрока, `{1}` — имя группы, `{2}` — сколько врагов;
- `SuccessMessage`: `{0}` — ник игрока, `{1}` — имя группы;
- `NotifyMessage`: `{0}` — количество предметов, `{1}` — id предмета.

Значения по умолчанию:

```
AnnounceMessage    = <color=#ff9d00>Рядом появилась группа «{0}»: врагов {1}. Убей их ради добычи!</color>
GlobalSpawnMessage = <color=#ff5a5a>Случайный спавн! У игрока {0} появилась группа «{1}» — врагов {2}.</color>
SuccessMessage     = <color=#3cff8a>{0} справился с задачей — группа «{1}» уничтожена!</color>
NotifyMessage      = <color=#ffd700>Добыча: {0} шт. (id {1}).</color>
```

Любое сообщение можно отключить, выключив его переключатель (`Announce`, `GlobalAnnounce`,
`NotifyKiller`, `SuccessAnnounce`).

## Команды в чате

> **Команды доступны только администраторам сервера.** Обычному игроку мод ответит
> «Команда доступна только администраторам» и ничего не сделает.
>
> Префикс команды: **`.npcs`** (или короткий `.npcspawner`).

| Команда | Что делает |
|---|---|
| `.npcs help` | показывает список всех команд мода |
| `.npcs list` | выводит список групп, которые есть в `npcs.json` (чтобы не помнить названия) |
| `.npcs spawn <группа>` | появляет указанную группу НПС рядом **с тобой** |
| `.npcs spawnme <группа>` | то же самое — заспавнить группу у себя |
| `.npcs spawnfor <ник> <группа>` | появляет указанную группу рядом с **другим игроком** (по нику) |
| `.npcs random` | запускает **случайный** спавн прямо сейчас: сам выбирает игрока и группу, как по таймеру. Таймер после этого сдвигается, чтобы группа не пришла сразу второй раз |
| `.npcs loot <id НПС>` | показывает, какая добыча настроена для этого НПС и с каким шансом |
| `.npcs reload` | перечитывает `npcs.json` и `loot.json` **без перезапуска сервера** |
| `.npcs debug` | диагностика: кто из игроков в бою, сколько найдено замков, сколько групп |

### Примеры

```
.npcs list
.npcs spawn night
.npcs spawnfor Vex horde
.npcs loot 2111003460
.npcs reload
```

Команда `.npcs spawn` / `.npcs spawnfor` учитывает те же правила, что и автопавн:
если игрок в бою или рядом нет свободного места (замок, крыша) — мод ответит,
почему спавн не получился.

---

## Как это работает внутри

Каждые `IntervalMinSeconds`–`IntervalMaxSeconds` секунд мод:

1. собирает игроков онлайн, которые **не в бою** (если `SkipPlayersInCombat = true`);
2. выбирает случайного игрока и случайную группу из `npcs.json`;
3. для каждого НПС из группы выбирает случайную точку в радиусе `RandomAround` от игрока;
4. **проверяет точку**: если она в замке или под крышей — точка отбрасывается и берётся другая
   (до 15 попыток);
5. если у выбранного игрока свободного места нет (например, он в своём замке) — мод пробует
   до 3 других игроков; если мест нет ни у кого — спавн пропускается и пишется в лог;
6. когда НПС убивает **игрок** — тот получает добычу из `loot.json`;
7. когда убит **последний** НПС из группы — всем игрокам уходит сообщение «справился с задачей».

Крыша в V Rising существует только над замком, поэтому проверка «рядом плиты замка»
закрывает и замки, и крыши сразу.

## Как понять, что мод работает

Открой лог сервера (обычно `BepInEx/LogOutput.log`) и поищи по слову `NpcSpawner`. Там будет:

```
[NpcSpawner] NPC Spawner v1.6.0 loading...
[NpcSpawner] config dir: .../BepInEx/config/NpcSpawner
[NpcSpawner] configs: npcs=17 groups, loot=4 entries
[NpcSpawner] chat commands registered (.npcs help)
[NpcSpawner] NPC Spawner v1.6.0 loaded.
[NpcSpawner] ready. groups=17, loot=4, enabled=True
[NpcSpawner] следующий спавн через 412 сек (init)
[NpcSpawner] группа 'night': заспавнено 9 НПС у игрока NickName.
```

- Строка **«следующий спавн через N сек»** повторяется регулярно — значит таймер живой.
- Строка **«заспавнено N НПС у игрока …»** — спавн состоялся.
- Если вместо неё **«не нашлось свободного места (замки/крыши) — пропускаем спавн»** —
  все игроки были в замках; это нормально.

## Частые вопросы и проблемы

**Мод установлен, но конфигов нет.**
Значит мод не загрузился. Проверь в логе строку `Loading [NPC Spawner ...]`.
Если её нет — файл лежит не в `BepInEx/plugins/` или не установлен сам BepInEx.

**НПС не появляются сами.**
1. Проверь `IntervalMinSeconds` / `IntervalMaxSeconds` — по умолчанию это 5–10 минут.
2. В логе должна быть строка «следующий спавн через N сек» — если её нет, мод не инициализировался.
3. Если спавн пропускается с сообщением про замки/крыши — все игроки онлайн были в замках.
4. Быстрая проверка руками: `.npcs spawn night`.

**Команда отвечает «нет прав» / «только для администраторов».**
Выдай себе администратора в панели хостинга или в настройках сервера.

**В `NpcSpawner.cfg` не появились новые настройки после обновления.**
BepInEx дописывает только новые строки, а старые значения не меняет.
Удали `NpcSpawner.cfg` и перезапусти сервер — файл создастся заново со всеми настройками.

**Нет сообщения о добыче.**
Проверь, что для этого id НПС есть запись в `loot.json` (`.npcs loot <id>`)
и что `Chance` не слишком маленький.

**Нет сообщения «справился с задачей».**
Оно приходит только когда убит **последний** НПС из группы. Если часть НПС ушла по времени
(`LifetimeSeconds`) или их убили не игроки — сообщение не появится.

**НПС всё равно появляются в замке.**
Увеличь `CastleBlockRadius` (например, до `8`).

**Как узнать id НПС и предметов?**
[V Rising Mod Wiki → Prefabs](https://wiki.vrisingmods.com/prefabs/) или мод **KindredExtract**.
